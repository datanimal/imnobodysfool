# I'm Nobody's Fool

The website for [imnobodysfool.com](https://imnobodysfool.com): free three-minute practice rounds that teach people to spot scam texts.

- `index.html` is the home page.
- `emergency-call.html` is the first training.
- `CNAME` tells GitHub Pages the site's address.

To turn on email sign-ups, paste a mailing-list form address into the `SIGNUP_URL` line near the bottom of `index.html`.
